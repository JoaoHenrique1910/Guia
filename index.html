Guia de Bolso Git

Comandos Essenciais

git init

Cria um novo repositório Git local

git add .

Salva todas as alterações para o próximo commit

git commit -m "Mensagem"

Salva as alterações no histórico local

git push -u origin main

Envia os commits para o repositório remoto

git fetch

Verifica modificações no repositório remoto

git pull

Puxa as alterações do repositório remoto para o local

git clone [link]

Cria uma cópia local de um repositório remoto

git remote add origin [link]

Conecta o repositório local ao repositório remoto

Git Security (Cibersegurança)

git config commit.gpgsign true

Força a assinatura criptográfica GPG em todos os commits

git rm --cached [arquivo]

Remove arquivos rastreados (como chaves vazadas) sem apagar localmente

git log -p | grep "senha"

Audita o histórico de commits buscando por senhas vazadas

git rev-parse --verify HEAD

Verifica a integridade e validação do commit atual

Dica: Lembre-se de sempre dar Ctrl + S antes de fechar o projeto
