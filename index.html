Comandos Essenciais

git init

Cria um novo repositório Git

git add .

Salva todas as alterações

git commit -m "[Mensagem de Commit]"

Salva minhas alterações no histórico local

git push -u origin main

Envia os meus commits locais para o repositório remoto

git fetch

Verifica se o reporitório remoto tem modificações em relação ao local

git pull

Puxa as alterações feitas no reporitório remoto para o local

git clone [link do reporitório

Cria uma cópia local de um reporitório remoto

git remote add origin [link do repositório]

Conecta o repositório local ao reporitório remoto

Dicas: Lembre-se de sempre dar Ctrl + S antes de fechar o projeto
