# 🗺️ Projeto Guia

O **Projeto Guia** Ele funciona de forma integrada ao meu portfólio principal e foi o primeiro projeto que fiz para treinar como organizar meus arquivos e estruturar um site.

🔗 [Você pode ver o Projeto Guia funcionando aqui](https://joaohenrique1910.github.io/Guia/)

---

## Por que decidi criar este projeto?

Estudando no Senac Largo Treze, foi o primeiro projeto feito para testar minhas habilidades construídas até o momento:
1. **Código limpo:** Escrever um HTML simples e bem estruturado, que qualquer pessoa consiga ler e entender.
2. **Estilização com calma:** Aprender a paciência de alinhar blocos, escolher espaçamentos e cuidar do visual usando apenas o CSS puro.
3. **Aprender com os erros:** Entender que errar faz parte do processo e que cada pequeno bug resolvido me torna um programador melhor.

---

## O que foi usado aqui?

* **HTML5:** Para criar a estrutura semântica da página.
* **CSS3:** Para cuidar das cores, tamanhos, fontes e deixar o visual harmonioso.
* **JavaScript:** Onde dou meus primeiros passos com a lógica do front-end.
