# 🗺️ Projeto Guia

O **Projeto Guia** Ele funciona de forma integrada ao meu portfólio principal e foi o primeiro projeto que fiz para treinar como organizar meus arquivos e estruturar um site.

🔗 [Você pode ver o Projeto Guia funcionando aqui](https://joaohenrique1910.github.io/Guia/)

---

## Por que decidi criar este projeto?

Estudando no Senac Largo Treze, foi o primeiro projeto feito para testar minhas habilidades construídas até o momento:
1. **Código limpo(HTML):** Escrever um HTML simples e bem estruturado, que qualquer pessoa consiga ler e entender.
2. **Estilização (CSS):** Escolher espaçamentos e cuidar do visual usando apenas o CSS puro.

---

## O que foi usado aqui?

* **HTML5:** Para criar a estrutura semântica da página.
* **CSS3:** Para cuidar das cores, tamanhos, fontes e deixar o visual mais atrativo.
